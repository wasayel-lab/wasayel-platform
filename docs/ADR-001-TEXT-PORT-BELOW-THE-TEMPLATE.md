## ١. السِياق — ما الَّذي بَقِيَ، ولِماذا هو وَحدَه

بَعدَ المَوجَة الحادِيَة عَشرَة صارَ دَينُ النَصّ الحَرفيّ ‏**31 سِلسِلَة
في 12 مِلَفّ razor** بَعدَ ‏139، والتَغطِيَة ‏**98.2 %** بَعدَ ‏93.0.
والباقي **لَيسَ طابوراً واحِداً**: ثَلاثَةٌ وعِشرونَ مِنها **لا تُرَحَّل
أَبَداً** (استِثناءاتٌ مُعلَنَةٌ في السِجِلّ: أَنماطُ مُطابَقَةٍ لِمُخرَجِ
النَموذَج، وقيَمٌ تُخَزَّن، وتَشخيصُ مُطَوِّر)، **وأَربَعَةَ عَشَرَ
يَحجُبُها حاجِزٌ بِنيَويّ** — وهي مَوضوعُ هذا القَرار.

**والحاجِزُ اثنان لا واحِد.** والخَلطُ بَينَهُما هو ما جَعَلَ المَوجاتِ
السابِقَةَ تَقول «انعِكاسُ اعتِماد» عَن مَواضِعَ لا اعتِمادَ فيها
أَصلاً.

### الحاجِزُ الأَوَّل — اتِّجاهُ الاعتِماد (‏13 مَوضِعاً)

`L` يَعيش في `ACommerce.Templates.Customer.Marketplace`، وهو المَشروعُ
**الَّذي يُرجِعُ إلى** الوِدجات والعُدَد:

```
ACommerce.Templates.Customer.Marketplace   ← فيه L
        │  يُرجِع إلى
        ├── ACommerce.Widgets
        ├── ACommerce.Templates.Shared
        └── ACommerce.Kit.Maps.Web
```

فَحَقنُ `L` في الفُروع **يَقلِب السَهم**. والمَقيسُ اليَوم:

| المَشروع | المِلَفّ | سَلاسِل |
|---|---|---|
| `ACommerce.Widgets` | `AcAttrEditor.razor` | ‏3 |
| | `AcAttrGrid.razor` | ‏2 |
| | `AcSpaceCard.razor` | ‏2 |
| | `AcLanguageToggle.razor` | ‏1 |
| | `AcListRow.razor` | ‏1 |
| `ACommerce.Templates.Shared` | `AcErrorState.razor` | ‏2 |
| `ACommerce.Kit.Maps.Web` | `AcLocationInput.razor` | ‏1 |
| | `AcMapPin.razor` | ‏1 |
| **المَجموع** | **‏8 مِلَفّات** | **‏13** |

> **تَصحيحٌ مَقيس**: `docs/I18N.md` §٨-د-ج تَقول «اثنَتا عَشرَة».
> العَدُّ اليَوم **ثَلاثَ عَشرَة**، والسِجِلّ هو المَقيس.

### الحاجِزُ الثاني — تَرتيبُ التَهيئَة (‏1 مَوضِع، وهو الأَهَمّ)

```csharp
[Parameter] public string YesLabel { get; set; } = "نَعَم";
```

مُهيِّئُ الحَقل يَعمَل **عِندَ الإنشاء، قَبلَ الحَقن**. فَحَتّى لَو صارَ
`L` مَحقوناً في الوِدجَة، **القيمَةُ الافتِراضِيَّة تَكون قَد كُتِبَت
أَصلاً**.

**والدَليلُ أَنّ الحاجِزَين مُستَقِلّان مَقيسٌ في المُستَودَع**:
`FlowExplainer.razor` يَعيش **داخِلَ مَشروعِ القالِب نَفسِه** — `L`
مَحقونٌ فيه ومُستَعمَلٌ في سَطرٍ آخَر — ومَعَ ذلك بَقِيَت فيه سِلسِلَةٌ
واحِدَة:

```csharp
[Parameter] public string Title { get; set; } = "كَيف تَتِمّ الصَّفقَة؟";
```

فَلَو كانَ الحاجِزُ اتِّجاهَ الاعتِماد وَحدَه لَما بَقِيَ هذا المَوضِع.
**نُزولُ `L` طَبَقَةً لا يُصلِحُه.**

### وثالِثٌ لا يَبلُغُه أَيُّ عَدّاد — يُقال ولا يُخفى

| المَوضِع | ما هو | العَدَد | لِماذا لا يُعَدّ |
|---|---|---|---|
| `DealTurnView.ActorLabelAr` | تَسمِياتُ فاعِلِ الصَفقَة، **يُصَيِّرُها razor** في `FlowExplainer` و`MyDealDetail` | ‏10 حَرفِيّات (‏6 قيَم مُتَمايِزَة) | دالَّةٌ **ساكِنَة** في `.cs`: لا razor يَعُدُّها، ولا مَصرِفَ مُعلَناً يَلتَقِطُها |
| `SmtpEmailChannel` | مَوضوعُ رِسالَةِ التَحَقُّق («رَمز التَّحَقُّق») | ‏1 | عُدَّةٌ (`…Auth.Providers.Smtp`) — نَفسُ الحاجِزِ الأَوَّل. **يَعُدُّها** مَصرِفُ `Subject =` |
| `StatusHelpers` | تَسمِياتُ حالاتٍ عَرَبِيَّة/إنجليزِيَّة | ‏11 | **صِفرُ مُستَهلِك** (مَقيس) — ‏كودٌ مَيِّت لا دَين |

**و`StatusHelpers` قَرارٌ مُنفَصِلٌ عَن هذا الـADR**: القاعِدَة ١ تَقول
«لا تَجريدَ قَبلَ مُستَهلِكِه»، وصِفرُ مُستَهلِكٍ يَعني الحَذفَ لا
التَرحيل. يُقال هُنا لِأَنَّه ظَهَرَ في نَفس القِياس.

## ٢. الخِيارات — وثَمَنُ كُلٍّ مَقيساً

### أ. مَشروعُ نَصٍّ ورَقيّ (leaf) يَراهُ الجَميع

يُستَخرَج `L` و`LocaleCatalog` و`LocaleValidator` إلى
`ACommerce.Platform.I18n` — مَشروعٌ **بِلا مَراجِع**، تُرجِعُ إلَيه
الوِدجاتُ والعُدَدُ والقالِب مَعاً. السَهمُ لا يَنقَلِب؛ يَنزِل الهَدَف.

* **يَحُلّ**: الحاجِزَ الأَوَّل كامِلاً (‏13 + 1 في SMTP).
* **لا يَحُلّ**: الحاجِزَ الثاني — القيمَةُ الافتِراضِيَّة تَبقى تُنَفَّذ
  قَبلَ الحَقن.
* **الثَمَن**: مَشروعٌ سادِسٌ في الحَلّ، ومَورِدٌ مُضَمَّنٌ يَنتَقِل،
  و`csproj` واحِدٌ يُعَدَّل لِكُلّ مُستَهلِك. **والقاعِدَة ١ تُحاكِمُه**:
  لا يُنشَأ تَجريدٌ قَبلَ ثَلاثَةِ مُستَهلِكين — وهُنا **أَربَعَة**
  (وِدجات، Shared، Maps، Auth.Smtp)، فَالشَرطُ مُستَوفىً بِالقِياس لا
  بِالنِيَّة.

### ب. الوِدجَةُ لا تَحمِل كَلاماً — الصَفحَةُ تُمَرِّرُه

تُحَوَّل كُلُّ تَسمِيَةٍ إلى مُعامِلٍ **بِلا قيمَةٍ افتِراضِيَّة**،
وتُمَرِّرُها الصَفحَةُ الَّتي تَملِك `L`.

* **يَحُلّ**: الحاجِزَين مَعاً.
* **الثَمَن**: كُلُّ مَوضِعِ استِدعاءٍ يُعَدَّل، **ومَوضِعٌ يُنسى يَصير
  فَراغاً على الشاشَة** لا خَطَأَ بِناء (إلّا بِـ`[EditorRequired]`،
  وهي تَحذيرٌ لا خَطَأ).
* **ومَعَ ذلك هو الأَنظَف مَفهومِيّاً**: الوِدجَةُ زينَةٌ، والصَفحَةُ
  تَملِك الكَلِمات.

### ج. الافتِراضيُّ `null` يُحَلُّ عِندَ التَصيير

```csharp
[Parameter] public string? YesLabel { get; set; }
...
@(YesLabel ?? L["widgets.attr.yes"])
```

* **يَحُلّ**: الحاجِزَ الثاني وَحدَه — ويَبقى مُحتاجاً إلى (أ) لِيَبلُغَ
  `L` أَصلاً داخِلَ الوِدجَة.
* **الثَمَن**: صِفرُ تَغييرٍ في مَواضِع الاستِدعاء. وهذا هو المُقتَرَحُ
  الَّذي سَجَّلَته §٨-د-ج، **وهو نِصفُ الحَلّ لا كُلُّه**.

### د. دالَّةُ التَسمِيَة تُرجِعُ **مِفتاحاً** لا جُملَة

لِلثالِثِ الساكِن (`DealTurnView`):

```csharp
public static string ActorLabelKey(string actorKey, DealSide side) => …  // "deals.actor.you"
// وفي razor:  @L[DealTurnView.ActorLabelKey(turn.ActorKey, mySide)]
```

* **يَحُلّ**: التَسمِياتِ الساكِنَة **بِلا حَقنٍ ولا مَشروعٍ جَديد** —
  الدالَّةُ تَبقى نَقِيَّةً ساكِنَة، والنَصُّ يَنتَقِل إلى المَعجَم،
  والمُقَرِّرُ هو razor الَّذي يَملِك `L` أَصلاً.
* **الثَمَن**: ‏6 مَفاتيح ومَوضِعا استِدعاء.
* **وهو رَخيصٌ ومُستَقِلّ**: يُنَفَّذ ولَو رُفِضَ (أ) و(ب) مَعاً.

## ٣. المُقتَرَح

**(أ) + (ج) مَعاً، و(د) مُنفَصِلَةً وقَبلَهُما.**

1. **(د) أَوَّلاً** — الأَرخَص، ولا يَمَسّ اتِّجاهَ اعتِماد: تَسمِياتُ
   `DealTurnView` تَصير مَفاتيح. ‏10 حَرفِيّات تَخرُج مِن الكود بِـ6
   مَفاتيح ومَوضِعَي استِدعاء.
2. **(أ) ثُمَّ (ج)** — مَشروعُ نَصٍّ ورَقيّ، ثُمَّ الافتِراضيُّ `null`
   يُحَلُّ عِندَ التَصيير. الأُولى وَحدَها لا تَكفي، والثانِيَةُ وَحدَها
   لا تَبلُغ.
3. **(ب) مَرفوضَةٌ كَخِيارٍ عامّ** — ثَمَنُها مَوضِعُ استِدعاءٍ يُنسى
   فَيَصير فَراغاً على الشاشَة، وذاك عَطَبٌ **مَرئيّ لِلمُستَخدِم** بَدَل
   دَينٍ مَقيسٍ في سِجِلّ.

**وشَرطُ الإقرار**: لا يُنَفَّذ شَيءٌ مِن هذا حَتّى يُقَرَّ. والدَينُ
مُثَبَّتٌ حَتّى ذلك الحين في `scripts/verify-i18n-debt-ledger.txt`
بِأَسماءِ مِلَفّاتِه — فَلا يَنمو صامِتاً.

## ٤. ما يَتَرَتَّب على القَبول، وما يَتَرَتَّب على الرَفض

| | إن قُبِل | إن رُفِض |
|---|---|---|
| التَغطِيَة | تَبلُغ ‏**99.6 %** (‏14 سِلسِلَة تَخرُج، ويَبقى ‏17 استِثناءً مُعلَناً) | تَقِف عِندَ ‏**98.2 %** |
| زِرُّ اللُغَة (‏§٦) | يَبقى شَرطُه الأَوَّل (‏100 %) غَيرَ مُستَوفىً بِـ17 استِثناءً **مُعلَناً**، وهو شَرطٌ يُراجَع لا يُهمَل | نَفسُه، مُضافاً إلَيه ‏14 مَوضِعاً **عَرَبِيّاً حَتماً** في وِدجاتٍ يَراها كُلُّ دَور |
| الوِدجات | تَصير قابِلَةً لِلتَرجَمَة، وهي المُشتَرَكُ بَينَ كُلّ الأَدوار | تَبقى العَرَبِيَّةُ مَخبوزَةً فيها، فَأَيُّ لُغَةٍ ثانِيَة **تُعرَض مَخلوطَة** |
| القاعِدَة ٢ | الحَدُّ الجَديد (لا نَصَّ في وِدجَة) يَحتاج **فاحِصاً يُفشِلُه** وإلّا انهار | لا حَدَّ جَديد، ولا فاحِصَ يُضاف |

**وسَطرٌ أَخيرٌ يُقال بِصَراحَة**: الرَفضُ خِيارٌ مَشروع. هذِه الأَربَعَةَ
عَشرَةَ **تَعمَل**، والمُنتَجُ عَرَبيٌّ أَوَّلاً، وكُلفَةُ (أ) مَشروعٌ
يُنشَأ. القَرارُ يَستَحِقّ أَن يُؤَجَّل إلى اليَومِ الَّذي تُطلَب فيه
لُغَةٌ ثانِيَةٌ فِعلاً — **بِشَرطِ أَن يُقرَأَ هذا المِلَفّ يَومَها بَدَل
أَن يُعادَ اكتِشافُ الحاجِزَين مِن الصِفر.** وذاك سَبَبُ كِتابَتِه.

## ٥. التَنفيذ — ما قيسَ بَعدَه، وأَينَ خالَفَ ما قيلَ قَبلَه

**‏2026-08-22.** نُفِّذَ (د) و(أ) و(ج)، ورُفِضَت (ب) كَما اقتُرِح.

### ٥.١ ما تَحَرَّك

| | قَبل | بَعد |
|---|---|---|
| حَرفِيّاتٌ في `.razor` (تَكرارات) | ‏31 | **‏17** |
| سَلاسِلُ مُتَمايِزَة | ‏29 | **‏17** |
| مِلَفّاتٌ تَحمِل دَيناً | ‏12 | **‏3** |
| مَصرِفٌ خارِجَ `.razor` | ‏1 | **‏0** |
| مَفاتيحُ `ar.json` | ‏1552 | **‏1571** (‏+19) |
| التَغطِيَة | ‏98.2 % | **‏98.9 %** |
| الاختِبارات | ‏927 أَرضِيَّة | **‏934 خَضراء** |

الباقي ‏17، كُلُّه **استِثناءٌ مُعلَنٌ في السِجِلّ** لا دَينٌ يُنتَظَر:
‏13 قيمَةً تُخَزَّن أَو تُطابِق مُخرَجَ نَموذَج (‏`StudioStudy`،
`TenantListingDetail`)، و4 تَشخيصُ مُطَوِّرٍ في `console.warn` وسَطرِ
لوغ (‏`App.razor`). **صِفرٌ مِنها يَحجُبُه حاجِزٌ بِنيَويّ** — وهذا هو
ما وُعِدَ بِه هذا القَرار وقَد وَقَع.

### ٥.٢ الانحِرافُ الأَوَّل — «‏99.6 %» رَقَمٌ لا يُبلَغ، وكانَ خَطَأً حِسابِيّاً

جَدوَلُ §٤ يَقول «تَبلُغ **‏99.6 %** (‏14 سِلسِلَة تَخرُج، ويَبقى ‏17
استِثناءً مُعلَناً)». والمَقيسُ **‏98.9 %**، والفَرقُ لَيسَ نَقصاً في
التَنفيذ بَل **تَناقُضاً داخِلَ الجُملَة نَفسِها**:

```
COVERAGE = keys / (keys + distinct-still-literal)      ← تَعريفُ الفاحِص
‏98.9 % = 1571 / (1571 + 17)
‏99.6 % لا تُبلَغ إلّا بِـ distinct ≤ 6
```

أَي أَنّ «‏17 استِثناءً يَبقى» و«‏99.6 %» **لا يَجتَمِعان**: الأُولى
تُثَبِّت المَقامَ عِندَ ‏1588، والثانِيَةُ تَفتَرِضُه ‏1577. الرَقَمُ
كُتِبَ تَقديراً ولَم يُشتَقّ مِن الصيغَة — وهو بِعَينِه ما تَنهى عَنه
القاعِدَة ١٠. **والسَقفُ الحَقيقيّ مَعروفٌ الآن**: ما دامَت الـ‏17
استِثناءً مُعلَناً، فَالتَغطِيَةُ لا تَتَجاوَز ‏98.9 % مَهما رُحِّل —
تَرتَفِع فَقَط بِنُمُوّ القامُوس، وذاك ارتِفاعٌ لا يَعني شَيئاً.

### ٥.٣ الانحِرافُ الثاني — الاسمُ المَنطِقيُّ لِلمَورِد **تَغَيَّر**، ومُقاسٌ لا مَظنون

نَقلُ `Locales/*.json` إلى مَشروعٍ آخَر يُغَيِّر اسمَ المَورِد
المُضَمَّن، وانكِسارُه **صامِتٌ**: البِناءُ يَخضَرّ والقامُوسُ يَعود
فارِغاً في وَقتِ التَشغيل. فَقيسَ مِن التَجميعَةِ المَبنِيَّة لا مِن
النِيَّة:

```
ACommerce.Platform.I18n.Locales.ar.json      ← GetManifestResourceNames()
ACommerce.Platform.I18n.Locales.en.json
```

و`ResourcePrefix` في `LocaleCatalog` نُقِلَ مَعَه
(‏`ACommerce.Templates.Customer.Marketplace.I18n.Locales.` →
`ACommerce.Platform.I18n.Locales.`)، وتَجميعَةُ القالِب لَم يَعُد فيها
مَورِدُ لُغَةٍ واحِد (مَقيس). **والاسمُ المَنطِقيُّ لَم يُحفَظ كَما
كان — بَل حُفِظَ الاتِّساقُ بَينَه وبَينَ قارِئِه**، وهو الشَرطُ
الفِعليّ؛ وحِفظُ الاسمِ القَديمِ بِـ`LogicalName` كانَ سَيُبقي
مَشروعاً وَرَقيّاً يُسَمّي مَوارِدَه بِاسمِ مَشروعٍ لا يَعرِفُه.

### ٥.٤ حارِسُ التَطابُقِ البايتيّ — ومَقيسٌ بِحَقنِ عَيب

القاعِدَة ١١ تُوجِب أَن تُبرهَنَ كُلُّ دَفعَةِ تَرحيلٍ بِمُقارَنَةٍ
بايتيَّة. وقيَمُ `DealTurnView` السِتُّ يَحرُسُها الآن
`MigratedActorLabels_AreByteIdentical_ToThePreMigrationLiterals`:
حَرفِيّاتُه **مَنسوخَةٌ آليّاً** مِن `git show HEAD:…/DealTurnView.cs`
لا مُعادَةُ الكِتابَة — وإعادَةُ الكِتابَةِ هي بِعَينِها ما يُسقِط
التَشكيل.

**والحارِسُ نَفسُه قيسَ قَبلَ أَن يُوثَقَ بِه** (القاعِدَة ١٠): حُذِفَت
شَدَّةٌ واحِدَة (‏U+0651) مِن `deals.actor.platform` فَاحمَرَّ فَوراً،
ثُمَّ أُعيدَ المِلَفّ و`cmp` يُثبِت تَطابُقَه، والـ‏934 خَضراء.

### ٥.٥ الانحِرافُ الثالِث — البَوّابَةُ البَصَرِيَّة **لَم تُشَغَّل**، والسَبَبُ يُسَمّى

القاعِدَة ١١ تُوجِب مَعَ التَطابُقِ البايتيِّ لِلقيَم **مُقارَنَةَ
المُخرَجِ المُصَيَّر** (‏`capture-appearance.sh` /
`compare-appearance.sh`). ولَم تُشَغَّل، وهذا نَقصٌ يُعلَن لا يُخفى.

**السَبَبُ مَقيسٌ بِنِداءٍ حَقيقيّ لا مَظنون**: الخادِمُ لا يُقلِع —
‏`Npgsql` تُرجِع `28P01 password authentication failed` لِلمُستَخدِم
`neondb_owner` في مُحاوَلَتَين مُتَتالِيَتَين، مِن مِلَفِّ الاتِّصال
القائِم (‏`/d/Testor/neon-connection.txt`, ‏2026-08-11). أَي أَنّ
**الاعتِمادَ مَرفوضٌ مِن الخادِم**، لا أَنّ الأَداةَ غائِبَة — وهذا
تَمييزُ القاعِدَة ١٤: يُبلَّغ بِالنّاقِصِ تَحديداً (كَلِمَةُ مُرورِ
فَرعِ Neon) لا بِـ«لا يُنَفَّذ».

**وما يَحُلّ مَحَلَّها مُؤَقَّتاً، وحُدودُه**: ‏934 اختِباراً، والطَبَقاتُ
الساكِنَةُ السَبعُ خَضراء (ومِنها الطَبَقَة ٧ نَفسُها)، وحارِسُ
التَطابُقِ البايتيّ لِلقيَم المَنقولَة. وهذِه تُثبِت أَنّ **القيمَةَ**
لَم تَتَبَدَّل؛ ولا تُثبِت أَنّ **الصَفحَةَ** لَم تَتَبَدَّل — والفَرقُ
حَقيقيّ: مُعامِلٌ صارَ `string?` قَد يُصَيَّر فَراغاً لَو نُسِيَ
سُقوطُه، وذاك ما تُمسِكُه اللَقطَةُ وَحدَها. **فَالبَوّابَةُ دَينٌ
مُستَحَقٌّ على أَوَّلِ جَلسَةٍ يَعمَل فيها الاتِّصال**، وهي أَوَّلُ ما
يُشَغَّل عَلَيها.

**وقيسَ ما يُمكِن قِياسُه ساكِناً مِن ذلك الخَطَر بِعَينِه**: كُلُّ
مُعامِلٍ فَقَدَ افتِراضَه المَخبوز (‏10 مَواضِع في 5 مِلَفّات —
`FlowExplainer.Title`، و`SelectPlaceholder`/`YesLabel`/`NoLabel` في
`AcAttrEditor` و`AcAttrGrid`، و`VerifiedLabel`/`FeaturedLabel` في
`AcSpaceCard`، و`Title`/`RetryLabel` في `AcErrorState`) لَه `??` عِندَ
**كُلّ** مَوضِعِ تَصيير — ‏10 مِن 10، بِلا مَوضِعٍ عارٍ واحِد. فَخَطَرُ
«الفَراغُ على الشاشَة» الَّذي أَسقَطَ الخِيارَ (ب) **مَنفيٌّ لَفظِيّاً
هُنا**، ويَبقى ما لا يَنفيه اللَفظُ: تَرتيبُ العُقَد والمَسافاتُ في
HTML المُصَيَّر.
