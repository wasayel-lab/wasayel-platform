# ADR-002 — الباقَةُ بِسِعرٍ يَمنَحُها بَشَر، لا زِرّ

> **الحالَة: مُنَفَّذ — ‏2026-08-22.** الكودُ والاختِبارات في نَفس
> الكوميت. وما لَم يُتَحَقَّق مِنه حَيّاً مَذكورٌ في §٦ ولا يُدَّعى.

---

## ١. السِياق — العَطَبُ مَقيسٌ لا مَظنون

`POST /{slug}/plans/{planId}/subscribe` كانَ جِسمُه سِتَّةَ أَسطُر:

```
var plan = await s.LoadAsync<Plan>(planId);
if (plan is null) return Results.Redirect(…"plans");
var ev = new SubscriptionCreated(
    Guid.NewGuid(), userId, planId, plan.ListingsQuota, plan.DaysPeriod, DateTime.UtcNow);
s.Events.StartStream<Subscription>(ev.Id, ev);
await s.SaveChangesAsync();
```

يُحَمِّلُ الباقَةَ، **ويَتَجاهَل `Price`**، ويَفتَح الاشتِراكَ لِأَيّ
مُستَخدِمٍ مُسَجَّلٍ بِنَقرَةٍ واحِدَة. أَي أَنّ **حِصَّةَ الإعلانات**
— وهي عَينُ الشَيءِ الَّذي يَحرُسُه الاستِحقاقُ على
`POST /{slug}/listings/create` — كانَت تُمنَح مَجّاناً مِن زِرٍّ
مَعروضٍ في `/​{slug}/plans` لِكُلّ داخِل.

وهذا **لَيسَ ثَغرَةً نَظَرِيَّة**: قَرارُ المالِك حَرفِيّاً «أُوافِق
على إنشاء المُستَخدِمين وتَرقِيَتِهم يَدَوِيّاً» و«يُمكِنُني البَدءُ
بِقَبول المَدفوعات كَحَوالاتٍ بَنكِيَّة». فَما دامَ القَبضُ يَدَوِيّاً،
فَكُلّ اشتِراكٍ يُفتَح بِلا قَرارٍ بَشَريّ هُوَ إيرادٌ لا يُقبَض.

**وسابِقَةٌ في نَفس الصِنف** تُثبِت أَنّ هذا لَيسَ حادِثاً مُفرَداً:
`POST /{slug}/api/subscriptions/start` كانَ يَمنَح حِصَّةً لِأَيّ
`UserId` يُكتَب في جِسم الطَلَب — حُذِفَ في مَوجَةِ الثَغرَة (‏راجِع
`SubscriptionHandlers`). فَبَقِيَ **المَسارُ الحَيّ** وَحدَه بِنَفس
العَطَب مِن جِهَة المال، وإن كانَ مَحروساً مِن جِهَة الهُوِيَّة.

---

## ٢. القَرار

**الباقَةُ الَّتي `Price > 0` لا تُمنَح ذاتِيّاً.** نَقرَةُ «اشتَرِك»
تَفتَح **طَلَبَ اشتِراكٍ مُعَلَّقاً**، ويُعرَض لِصاحِبِه رَقمُ مَرجِعٍ
وتَعليماتُ تَحويلٍ بَنكيّ. والمَنحُ يَقَع **عِندَ اعتِماد المُشرِف**
وحينَئِذٍ يُطلَق **نَفسُ** `SubscriptionCreated` القائِم.

**والباقَةُ المَجّانِيَّة (`Price == 0`) تَبقى ذاتِيَّةً كَما هي** —
نَفسُ الحَدَث، ونَفسُ المَجرى، ونَفسُ التَحويل. لَيسَ في مَنح
المَجّانيّ مَجّاناً تَسريب.

**والمَسارُ العامّ لَم يَتَغَيَّر**: `POST /{slug}/plans/{planId}/subscribe`
بِحَرفِه — فَلا نَموذَجٌ يَنكَسِر، ولا رابِطٌ يَتيه.

## ٣. البَدائِلُ المَرفوضَة، وسَبَبُ رَفضِها

| البَديل | لِماذا رُفِض |
|---|---|
| **بَوّابَةُ دَفعٍ الآن** | المالِكُ قالَ صَراحَةً إنَّه يَبدَأ بِحَوالاتٍ بَنكِيَّة. بَوّابَةُ دَفعٍ تَعني مُزَوِّداً وعَقداً وتَسوِيَةً واستِرداداً — أَي مَوجَةً كامِلَةً تَحجُب إغلاقَ تَسريبٍ يُغلَق اليَوم. |
| **إخفاءُ زِرّ الباقات المَدفوعَة** | يُغلِق التَسريبَ ويَقتُل البَيع مَعَه. والباقَةُ الَّتي لا تُطلَب لا تُباع. |
| **دَورَةُ حالاتٍ خاصَّةٌ بِالاشتِراك** | المُستَودَعُ فيه دَورَةُ اعتِمادٍ واحِدَة يَشتَرِكُ فيها الأَدوارُ والمَظهَرُ وتَعريفاتُ الباقات (`ApprovalFlow`). مَعجَمٌ رابِعٌ كانَ سَيَنجَرِف — وهي بِعَينِها العِلَّةُ الَّتي وَحَّدَت `TenantRoleStatuses` و`TenantThemeStatuses` مِن قَبل. |
| **تَعليماتُ تَحويلٍ حَرفِيَّةٌ في الكود** | حِسابُ كُلّ مَتجَرٍ يَختَلِف، وتَغييرُ آيبانٍ كانَ سَيَصير إصداراً. صارَت حَقلاً في وَثيقَة المُستَأجِر بِجِوار الهُوِيَّة البَصَرِيَّة، يُحَرِّرُه المُشرِف. |

## ٤. الانحِرافُ المُعلَن — الحارِسُ حارِسُ **مُشرِف المَتجَر**

نُقطَتا `decide` القائِمَتانِ — تَعريفُ الدَور والثيم — مَحروسَتانِ
بِـ`PlatformAdminGuard`. **ونُقطَةُ قَرارِ الاشتِراك مَحروسَةٌ
بِـ`TenantAdminGuard`**، وهذا انحِرافٌ عَن جارَتَيها يُكتَب هُنا بَدَلَ
أَن يُلاحَظ لاحِقاً.

**السَبَب**: تِلكَ قَراراتُ مَنصَّة — تَعريفُ الدَور يُضيف دَوراً
**خارِجَ كاتالوج المَنصَّة** بِصَلاحِيّاتِه، والثيمُ يُبَثّ في `<head>`
لِكُلّ زائِر. أَمّا هذا فَإقرارُ **حَوالَةٍ وَصَلَت حِسابَ المَتجَر**؛
وتَعليماتُ التَحويل نَفسُها حَقلٌ في وَثيقَة المُستَأجِر يُحَرِّرُها
مُشرِفُه. **فَمَن يَقبِض هُوَ مَن يُقِرّ.**

وحَصرُ القَرار في مُشرِف المَنصَّة كانَ سَيَجعَل كُلّ مَتجَرٍ
يَنتَظِرُنا لِيَقبِضَ ثَمَنَه — أَي عُنقَ زُجاجَةٍ في مَسار الإيراد،
لا حِراسَةً.

**وهُوَ نَفسُ الحارِس** الَّذي يَحرُس بَقِيَّةَ
`/admin/tenants/{slug}/…`: مالِكُ المَتجَر مِن الاستوديو، أَو مُستَخدِمٌ
دَورُه الفَعّال يَحمِل `tenant.manage`. **ومُستَخدِمٌ عادِيٌّ لا
يَعتَمِد طَلَبَ نَفسِه** — مَقيسٌ بِوَحدَتَين: واحِدَةٌ تُثبِت أَنّ
القَرارَ يَرفُضُه، وأُخرى تُثبِت أَنّ النُقطَةَ **تَسأَلُ الحارِسَ
قَبلَ أَوَّل كِتابَة**. والثانِيَةُ شَرطٌ لِلأولى: حارِسٌ لا يُنادى
لَيسَ حارِساً.

## ٥. الشَكلُ المُنَفَّذ

```
 /{slug}/plans  ← «اطلُب الاشتِراك»
      │
      ▼
 POST /{slug}/plans/{planId}/subscribe        (نَفسُ المَسار)
      │  Price == 0 ؟ ──► SubscriptionCreated  (كَما كان، بِلا تَغيير)
      │  Price >  0 ؟
      ▼
 SubscriptionRequest  status=pending  +  رَقم مَرجِع  SR-XXXXXXXX
      │  إشعارٌ لِمُشرِفي المَتجَر (مِن القامُوس لا مِن الكود)
      ▼
 /admin/tenants/{slug}/subscriptions          ← بِطاقَة في لَوحَة المَتجَر
      │  «اعتِماد» / «رَفض»   (TenantAdminGuard)
      ▼
 POST …/subscriptions/{reference}/decide
      │  approved ──► **نَفسُ** SubscriptionCreated
      └─ rejected ──► لا شَيء يُنشَأ
```

**ومانِعُ التَكرار حارِسانِ لا واحِد**: الحالَةُ تُفحَص (‏`pending`
وَحدَها تُقَرَّر)، و**مُعَرِّفُ مَجرى الاشتِراك يُولَّد عِندَ فَتح
الطَلَب** فَيَصير مُشتَقّاً مِن الوَثيقَة لا مِن لَحظَة النَقر — نَقرَتانِ
على «اعتِمِد» تُعطِيانِ نَفسَ المُعَرِّف، فَلَو أَفلَتَت الثانِيَةُ مِن
فَحص الحالَة رَدَّها Marten بِمَجرىً قائِم. وطَلَبٌ مُعَلَّقٌ **واحِدٌ
لِكُلّ (مُستَخدِم، باقَة)** فَلا يُطابَق مَرجِعانِ بِحَوالَةٍ واحِدَة.

### يُبلَغُ بِالنَقر (القاعِدَة ١٢)

| مَن | المَسار |
|---|---|
| المُشتَرِك | `/{slug}/me` ← «الباقات» ← «اطلُب الاشتِراك» ← بِطاقَةُ الطَلَب بِمَرجِعِه وتَعليمات التَحويل |
| المُشتَرِك (المُتابَعَة) | `/{slug}/me` ← بِطاقَة «طَلَبات الاشتِراك» بِحالَةِ كُلّ طَلَب |
| المُشرِف | `/admin` ← بِطاقَةُ المَتجَر ← «طَلَبات الاشتِراك» ← «اعتِماد» |
| المُشرِف (مِن داخِل المَتجَر) | `/{slug}/me` ← «إدارَة المَتجَر» ← «طَلَبات الاشتِراك» |
| تَحريرُ تَعليمات التَحويل | `/admin/tenants/{slug}` ← «الهُويَّة البَصَريّة» ← «تَعليمات التَحويل البَنكيّ» |

## ٦. حُدودُ ما تُحُقِّقَ مِنه — ولا يُدَّعى غَيرُه

**قاعِدَةُ البَيانات غَير مُتاحَة في جَولَة التَنفيذ** (الاعتِمادُ
مَرفوض `28P01`). فَالمُبرهَنُ هو:

- **القَرارُ نَفسُه** — ‏17 وَحدَةً نَقِيَّةً على
  `SubscriptionRequestPolicy` و`TenantAdminGuard`: باقَةٌ بِسِعر
  تُنتِج طَلَباً مُعَلَّقاً لا اشتِراكاً؛ ومَجّانِيَّةٌ تَبقى ذاتِيَّة؛
  والاعتِمادُ يَمنَح مَرَّةً واحِدَة والنَقرَةُ الثانِيَة تُرَدّ
  بِـ`request_already_decided`؛ والرَفضُ لا يُنشِئ شَيئاً؛ ومُستَخدِمٌ
  عادِيٌّ لا يُدير المَتجَر.
- **الحارِسُ مَوصولٌ فِعلاً** — مَقيسٌ نَصِّيّاً بِماسِح
  `WriteEndpointGuardTests` نَفسِه (لا ماسِحٌ ثانٍ): الحارِسُ في
  الجِسم، **وقَبلَ** أَوَّل كِتابَة.
- **باعِثُ `SubscriptionCreated` واحِدٌ كَما كان** — انتَقَلَ إلى
  `SubscriptionRequestService`، فَالمَسارانِ يَلتَقِيانِ عِندَ حَدَثٍ
  واحِد ولا يَنجَرِفانِ في الحِصَّة أَو المُدَّة.
- **البِناءُ بِصِفر أَخطاء، و‏951 اختِباراً خَضراء** (‏934 قَبلَها)،
  **والطَبَقاتُ الساكِنَةُ السَبع خَضراء** — ومِنها الطَبَقَةُ السابِعَة
  (‏صِفرُ نَصٍّ حَرفيٍّ جَديد: كُلُّ ما يَراه المُستَخدِمُ مِن `ar.json`)
  والثامِنَة (‏صِفرُ جَلسَةِ Marten في `.razor`).

**وما لَم يُبرهَن**: أَنّ الوَثيقَةَ تُخَزَّن وتُقرَأ مِن Postgres،
وأَنّ المَجرى يُفتَح عِندَ الاعتِماد، وأَنّ الشاشَتَينِ تُصَيَّرانِ
بِبَياناتٍ حَيَّة. تِلكَ عَقدُ `WASAYEL_LIVE_PROOF` ويَحتاج قاعِدَةً
عامِلَة. **الطَبَقَةُ السادِسَة والبَوّابَةُ البايتِيَّةُ مُعَطَّلَتانِ
بِغِياب القاعِدَة، ولا يُدَّعى تَشغيلُهُما.**
