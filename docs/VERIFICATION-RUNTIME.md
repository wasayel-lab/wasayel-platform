# الطَبَقَة السادِسَة — التَحَقُّق البَصَرِيّ الآلِيّ

> **لِماذا وُجِدَت.** لَوح المُتَصَفِّح في بيئَة المالِك لا يُرَكِّب إطاراً
> («screenshot timed out — pane is not displayed»)، فَصارَ كُلّ تَحَقُّق
> بَصَرِيّ قِياسَ قِيَم CSS بِـ`curl`. وقِيمَة CSS **لا تُثبِت تَخطيطاً**:
> اللَون الصَحيح قَد يَقَع على خَلفِيَّة تُبطِلُه، والعَرض الصَحيح قَد
> يَفيض عَن حاوِيَة لَم تُقَس. هذِه الطَبَقَة تُعيد الحُكم البَصَرِيّ
> **مِن صَفحَة حَيَّة**، مَقطوعَةَ الرَأس بِالكامِل — بِلا واجِهَة رَسومِيَّة
> ولا نَقرَة.

```bash
# القِياس النَظيف — الصَفَحات الخَمس الافتِراضِيَّة
dotnet run scripts/verify-runtime.cs

# نافِذَة الهاتِف — وهي المُعتَمَدَة لِلتَخطيط
dotnet run scripts/verify-runtime.cs -- --viewport 390x844

# صَفحَة بِعَينِها، تَقرير بِلا رَمز خُروج فاشِل
dotnet run scripts/verify-runtime.cs -- --report-only http://localhost:5050/ashare

# بُرهان أَنّ الأَداة تَرى (انظُر «بُرهان الالتِقاط» أَدناه)
dotnet run scripts/verify-runtime.cs -- --inject-preset contrast http://localhost:5050/ashare
```

`--json out.json` يَكتُب تَقريراً بِنيَوِيّاً. رَمز الخُروج: ٠ سَليم، ١ مُخالَفات، ٢ عَطَب تَشغيلِيّ.

## لِماذا لا Playwright

المُستَودَع القَديم يُنَفِّذ هذِه الطَبَقَة بِـ`verify-runtime.mjs` فَوقَ
Playwright. وهي **غَير قابِلَة لِلتَشغيل هُنا**، مُقاساً لا مُقَدَّراً:

| القِياس | النَتيجَة |
|---|---|
| `node --version` | `command not found` |
| `where node` (cmd) | فارِغ |
| `Get-Command node` (PowerShell) | فارِغ |
| مَسح `C:` و `D:` عَن `node.exe` بِعُمق ٤ | `NO-NODE-FOUND` |

فَلا Node ولا npm ولا npx — وبِالتالي لا Playwright، ولا يُبلَغ حَتّى
مَرحَلَة `npx playwright install`.

**لَكِنّ غِياب الأَداة لَيسَ غِياب القُدرَة.** المُتَوَفِّر بِالقِياس:

- Chrome ‏151 مُثَبَّت، ويَعمَل بِـ`--headless=new` (بِلا واجِهَة).
- يَتَكَلَّم **CDP** على `--remote-debugging-port`.
- .NET ‏10 — وهي عُدَّة المُستَودَع أَصلاً — فيها `ClientWebSocket`.

فَالمُحَرِّك المُستَعمَل هُنا **هو نَفسُه مُحَرِّك Playwright**
(‏Chromium يُقاد بِـCDP)؛ المُتَغَيِّر لِسان القِيادَة فَقَط: C# بَدَل
JavaScript. وكُلّ قِياس يَجري بِـ`getComputedStyle` و
`getBoundingClientRect` داخِل الصَفحَة — أَي بِنَفس مَصدَر الحَقيقَة.

وطُرِقَت ثَلاثَة مَسالِكَ أُخرى وسَقَطَت، وتُذكَر لِئَلّا تُعاد:

| المَسلَك | لِماذا سَقَطَ |
|---|---|
| إطار `<iframe>` يَقرَأ الصَفحَة | الخادِم يَبُثّ `X-Frame-Options: SAMEORIGIN` و`CSP: frame-ancestors 'self'` |
| إضافَة مُتَصَفِّح بِـ`content script` | لا تُحقَن في الوَضع مَقطوع الرَأس |
| قِيادَة CDP بِـ`curl` | يَذكُر `ws` في البُروتوكولات لَكِنّ سَطر الأَمر لا يُؤَطِّر رِسالَة طَلَب/رَدّ |

**ومِلَفّ `.cs` مُفرَد بِلا `.csproj`** عَمداً: لِئَلّا يَدخُل مَشروع جَديد
في الحَلّ فَيَمَسّ البِناء أَو عَدَّ الاختِبارات. تَشغيل المِلَفّ المُفرَد
مُتاح في .NET 10.

## عائِلات الفَحص

| الرَمز | السُؤال | مِن أَينَ |
|---|---|---|
| **A** أَنماط | هَل يُحَقِّق الوِدجِت أَدنى حَشوٍ وحَدٍّ وخَلفِيَّةٍ مُصَرَّحَة؟ | مَنقولَة |
| **B** تَموضُع | هَل الشَريط الثابِت فِعلاً عِند `y=0` بَعدَ التَمرير؟ | مَنقولَة |
| **C** احتِواء | هَل يَبقى الابن داخِل حُدود أَبيه (زَوج مَذكور)؟ | مَنقولَة |
| **D** مُحاذاة | هَل إخوَة الصَفّ على مَركَز أُفُقِيّ واحِد؟ | مَنقولَة |
| **E** تَداخُل | هَل تَركَب البِطاقات بَعضَها؟ | مَنقولَة |
| **F** قِيَم مَحسوبَة | مَقاس الخَطّ على السُلَّم، حَدّ مَرئِيّ، هَدَف لَمس ≥ ٣٢px | مَنقولَة |
| **G** تَبايُن | WCAG AA — ‏4.5:1، و3:1 لِلنَصّ الكَبير | مَنقولَة + تَحسين |
| **H** صُندوق | `border-box` حَيثُ يُوجَد قَيد عَرض مَع حَشو | مَنقولَة + تَضييق |
| **I** فَيَضان نَصّ | `scrollWidth > clientWidth` — نَصّ مَقصوص | مَنقولَة |
| **J** تَمرير أُفُقِيّ | هَل تُمَرَّر الصَفحَة أُفُقِيّاً أَصلاً؟ | **جَديدَة** |
| **K** مُلاءَمَة الحاوِيَة | هَل العُنصُر أَعرَض مِن أَبيه المُباشِر؟ | **جَديدَة** |

**وكُلّ عائِلَة تَطبَع عَدَد تَأكيداتِها**، لِأَنّ «صِفر مُخالَفَة» لا مَعنى
لَها ما لَم يُعرَف كَم تَأكيداً جَرى فِعلاً. **صِفرٌ مِن صِفر لَيسَ نَجاحاً**
— وهو الشَكل الَّذي تَتَنَكَّر فيه أَداةٌ عَمياء في صورَة أَداةٍ سَليمَة.

## العُقود — بُنِيَت، ولَم تُنقَل

عُقود المُستَودَع القَديم (`.ac-card`، `.ord-bottom-nav`، `.act-navbar`)
**لَم تُنقَل**: قِياس الصَفَحات الخَمس أَظهَرَ لَها **صِفر مُطابَقَة** هُنا.
ونَقلُها كانَ سَيُنتِج مِلَفّ عُقودٍ ضَخماً لا يَفحَص شَيئاً، ويُعطي «صِفر
مُخالَفَة» يُطمئِن كَذِباً — وهو بِعَينِه عَطَب «التَجريد بِلا مُستَهلِك».

المُستَبدَل بِها مُحَدِّدات **قِيسَت حاضِرَةً فِعلاً** في DOM حَيّ، وكُلّ
عَتَبَة مَسنودَة بِقاعِدَة CSS مَكتوبَة:

| المُحَدِّد | السَنَد |
|---|---|
| `.ac-space` | `premium.css:430` — ‏`border:1px` و`background:var(--ac-surface)` |
| `.acm-mobile-nav` | `app.css:92` — ‏`position:fixed; top:0` |
| `.acm-mobile-nav-inner` | `app.css:100` — ‏`flex row` + `align-items:center` |
| `.acs-page` | حاوِيَة الصَفحَة |

## بُرهان الالتِقاط — ولِماذا هو المِعيار

**أَن تُعطِيَ الأَداة صِفر مُخالَفات لا يُثبِت أَنَّها تَرى.** قَد تَسكُت
لِأَنّ مُحَدِّداتِها لا تُطابِق شَيئاً. فَالبُرهان الوَحيد أَن يُحدَث عَطَبٌ
مَعلوم، ويُثبَت أَنّ الأَداة تَصرُخ **وتُحَدِّد المَوضِع**، ثُمَّ يُرفَع
فَتَسكُت.

والحَقن يَجري **في الذاكِرَة عَبر CDP** (`--inject-preset`)، لا بِتَعديل
مِلَفّ CSS في المُستَودَع. وهذا أَسلَم وأَقوى مَعاً: أَسلَم لِأَنَّه لا
يُخَلِّف أَثَراً يُنسى إرجاعُه؛ وأَقوى لِأَنّ البُرهان يَصير **قابِلاً
لِلتَكرار في كُلّ جَولَة** بَدَلَ تَعديلٍ يَدَوِيّ يُثبِت مَرَّةً ثُمَّ يَزول.

النَتيجَة على `/ashare` — أَربَعَة أَعطاب، أَربَع صَرَخات مُوَضَّعَة:

| العَطَب | الصُراخ |
|---|---|
| `contrast` | `<h1> «عَشير» نِسبَة 1.77 < 3` و`<strong> «عَميل» 1.85 < 4.5`، بِـrgb الطَرَفَين |
| `overlap` | `.acm-role-landing-card: 3 أَزواج مُتَداخِلَة` |
| `touch` | `ارتِفاع 12.0px < 32px` |
| `overflow` | `عَرض 3042px > حاوِيَة .acm-role-landing-cards (568px)` |

وبِلا حَقن: **٣٧ تَأكيداً، صِفر مُخالَفَة، رَمز خُروج ٠**.

### وأَثمَن ما في البُرهان أَنَّه كَشَفَ عَمًى في الأَداة نَفسِها

العَطَب `overflow` (بِطاقَة عَرضُها 3000px) **مَرَّ دونَ أَن يُرى في ثَلاث
جَولات**:

1. فاتَ **C** لِأَنّ قَواعِد الاحتِواء تَفحَص أَزواج أَب/ابن **مَذكورَة
   بِأَسمائِها**، والزَوج لَم يَكُن مَذكوراً.
2. فاتَ **I** لِأَنّ `scrollWidth` الابن يُساوي `clientWidth`‌ه — لا فَيَضان
   **داخِلِيّ**؛ الفَيَضان كانَ بِالنِسبَة لِأَبيه.
3. فاتَ **J** — وقَد أُضيفَ خِصّيصاً لَه — لِأَنّ سَلَفاً قاصّاً
   (`overflow:hidden`، ‏`premium.css:324`) يَمنَع تَمرير الصَفحَة فَيُخفي
   الفَيَضان عَن مُستَوى المُستَند كُلِّه.

فَأُضيفَت **K**: مُقارَنَة الابن بِأَبيه مُباشَرَةً — وهي القِياس الوَحيد
الَّذي **لا يُخفيه القَصّ**. ولَولا الحَقن لَبَقِيَ هذا العَمى مَستوراً
خَلفَ «صِفر مُخالَفَة».

## ما اكتُشِف فِعلاً — أَعطاب قائِمَة

### ١. تَبايُن شَريط التَنَقُّل السُفلِيّ دونَ WCAG AA — في كُلّ الثيمات

يَظهَر على نافِذَة الهاتِف (‏٣٩٠×٨٤٤) فَقَط، لِأَنّ الشَريط لا يُرَكَّب
على العَرض الواسِع:

| الصَفحَة | النَصّ على الخَلفِيَّة | النِسبَة | المَطلوب |
|---|---|---|---|
| `/ashare/explore` | `#a1a1aa` على `#fafafa` | **2.46** | 4.5 |
| `/theme-demo` | `#7e9887` على `#f2f7f2` | **2.88** | 4.5 |

التَسميات المُتَأَثِّرَة: «الرَئيسيّة»، «مُفَضَّلَة»، «رَسائل»، «حِسابي».

**والجَذر لَيسَ في CSS بَل في رَمز الثيم.** القاعِدَة
`premium.css:723` تَقول `color: var(--ac-text-soft)`، و`--ac-text-soft`
تُشتَقّ مِن `--wsl-color-text-soft` المَبثوث لِكُلّ مُستَأجِر. أَي أَنّ
العَطَب **يُصلَح في مَوضِعٍ واحِد لِكُلّ المُستَأجِرين**، لا في وَرَقَة
أَنماط. ولِأَنّ الرَمز نَفسَه مُستَعمَل في مَواضِعَ أُخرى صَغيرَة الخَطّ
(‏`::placeholder`، ‏`.ac-search-icon`، ‏`.ac-listrow-time`،
‏`.ac-space-placeholder`) فَالأَثَر **مَنهَجِيّ لا مَوضِعِيّ**.

> لَم يُعَدَّل شَيء: `libs/` خارِج نِطاق هذِه الجَولَة، والقَرار في اللَون
> قَرار تَصميم يَخُصّ المالِك.

### ٢. قَصّ سِعر البِطاقَة على الهاتِف

`/ashare/explore` — ‏`.ac-space-price`: ‏`scrollWidth=151..160` مُقابِل
`clientWidth=145`، في خَمس بِطاقات. أَي أَنّ السِعر **يُقَصّ أُفُقِيّاً**
على عَرض الهاتِف.

## بَوّابَة CI — لِماذا لَم تُضَف

هذِه الطَبَقَة **تَحتاج خادِماً حَيّاً** (‏`localhost:5050` بِقاعِدَة
بَياناتِه) وثُنائِيَّ Chrome. وإدخالُها بَوّابَةً في `ci.yml` بِلا هَذَين
يُنتِج **بَوّابَةً تَفشَل دائِماً** — وهي أَسوَأ مِن غِياب البَوّابَة:
تُدَرَّب العَين على تَجاهُل الأَحمَر.

الشُروط الَّتي يَجِب أَن تَتَحَقَّق أَوَّلاً:

1. خُطوَة تُقيم الخادِم في الـworkflow مَع قاعِدَة بَيانات اختِبار.
2. تَثبيت Chrome على العامِل (‏`browser-actions/setup-chrome` أَو صورَة
   تَحمِلُه).
3. اِستِقرار المُحتَوى: العُقود تَعتَمِد بِطاقاتٍ تَأتي مِن البَيانات،
   فَقاعِدَةٌ فارِغَة تُعطي «صِفر مُطابَقَة» — أَي **نَجاحاً كاذِباً**، وهو
   الخَطَر الَّذي تُحَذِّر مِنه عَدّادات العائِلات أَعلاه.

وحَتّى تَتَحَقَّق، التَشغيل **يَدَوِيّ عِند العَمَل على الواجِهَة**، ورَمز
الخُروج جاهِز لِلبَوّابَة مَتى أُقيمَ الخادِم.

## حُدود الطَبَقَة

- **لا تَحكُم على الجَمال** — تَقيس هَندَسَةً وتَبايُناً، لا ذَوقاً.
- **لا تَرى الحَرَكَة** ولا الانتِقالات ولا الـhover.
- **تَرى ما رُكِّبَ فَقَط**: عُنصُرٌ لا يُرَكَّب على نافِذَةٍ ما لا يُفحَص
  عَلَيها — ولِذلِك يُقاس المَقاسان: المَكتَب والهاتِف.
- **العُقود يَدَوِيَّة**: مُحَدِّدٌ لا يُذكَر لا يُفحَص. والعائِلَتان J و K
  وَحدَهُما تَعمَلان بِلا تَعداد مُحَدِّدات.
