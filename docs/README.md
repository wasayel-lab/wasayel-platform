## ٣. طَبَقات التَحَقُّق الثَماني — وأَينَ تَعيش

التَفصيل الكامِل في [`VERIFICATION-LAYERS.md`](VERIFICATION-LAYERS.md)،
وهذا فِهرِسُها التَنفيذيّ. **خَمسٌ ساكِنَة** تَقرَأ المَصدَر وتَدخُل
بَوّابَة CI، **وواحِدَة حَيَّة** تَقرَأ صَفحَةً مُرَكَّبَة وتُشَغَّل
يَدَوِيّاً، **وسابِعَة وثامِنَة ساكِنَتان** تَحرُسانِ دَينَين يُقصَد
تَصفيرُهُما — نَصّاً حَرفِيّاً، وجَلسَةَ Marten في صَفحَة. والرَقم
**عُنوان يُحال إلَيه لا تَرتيب تَشغيل**.

```bash
./scripts/verify-static.sh          # الخَمس الساكِنَة + السابِعَة + الثامِنَة دَفعَةً واحِدَة (بَوّابَة CI)
```

خَرقٌ **جَديد** يُحمِر، وإدخالٌ **أُصلِحَ ولَم يُرفَع مِن السِجِلّ**

## ٤. أَدَوات البُرهان الثَلاث — ومَواضِعُها

لَيسَت طَبَقات تَحَقُّق، بَل **أَطراف مُقارَنَة** تُشَغَّل يَدَوِيّاً
عِندَ كُلّ تَحويل. تَحتاج **خادِماً حَيّاً على ‏:5050**، وتُسَخَّن
بِـ`curl` مَعَ إهمال الجَولَة الأولى بَعدَ إقلاع بارِد.

| الأَداة | ما تَقيسُه | مَتى تَكون **هي الحَكَم** |
|---|---|---|
| `scripts/compare-appearance.sh` | الـHTML **بايتاً بِبايت** خارِج كُتلَة `<style id="wsl-theme">` — ‏15 صَفحَة | حينَ يَتَغَيَّر razor أَو نَصّ أَو وَسم |
| `scripts/compare-computed.sh` | **النَمَط المَحسوب بَعدَ الكاسكيد** — ‏56 خاصِّيَّة × 1,298 عُنصُراً + المُستَطيل المُحيط | حينَ يَتَغَيَّر **CSS**: الوَسم لا يَتَغَيَّر أَصلاً، فَالأولى عَمياء عَنه |
| `scripts/verify-runtime.cs` | التَخطيط الحَيّ (‏الطَبَقَة ٦) — تَداخُل، مُحاذاة، مَوضِع، فَيض | حينَ يُشَكّ في **تَخطيط** لا في قيمَة |

```bash
# المَظهَر — ويُمَرَّر اسم الأَساس صَراحَةً
scripts/compare-appearance.sh tests/characterization/appearance/i18n-baseline

# النَمَط المَحسوب
scripts/compare-computed.sh   tests/characterization/computed/baseline
dotnet run scripts/dump-computed.cs -- <dir>      # لِالتِقاط أَساسٍ جَديد

# التَخطيط الحَيّ
dotnet run scripts/verify-runtime.cs -- [--viewport 390x844] <url>
```

> **مِصيَدَة مَقيسَة (‏2026-08-15)**: ‏`compare-appearance.sh` **بِلا
> وَسيط** تُقارِن بِـ`baseline/` وهي لَقطَة **عَتيقَة** (‏6 صَفَحات، مِن
> قَبل وُسوم SEO في `App.razor`) فَتَخرُج حَمراءَ على شَجَرَة نَظيفَة.
> الأَساس الحَيّ هو **`i18n-baseline/`** (‏15 صَفحَة). ولَم تُحَدَّث
> القَديمَة لِأَنّ `baseline/css/*` هو الطَرَف المُجَمَّد الَّذي تَقرَؤُه
> `ThemeZeroEquivalenceTests`. التَفصيل في
> [`../tests/characterization/appearance/README.md`](../tests/characterization/appearance/README.md).

ووَثيقَتا القِياس المُرافِقَتان — لَيسَتا تَوثيقاً بَل **أَدَوات**:
[`../tests/characterization/appearance/README.md`](../tests/characterization/appearance/README.md)
