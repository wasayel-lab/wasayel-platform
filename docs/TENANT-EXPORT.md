# التَخارُج — ماذا يَخرُج، وماذا لا يَخرُج، وما يَلزَمُ المُستَلِمَ أَن يَعرِفَه

> **مَرجِعٌ تَشغيليّ.** القَرارُ وسَبَبُه في
> [`ADR-020`](ADR-020-THE-EXIT-IS-THE-PRODUCT.md) — وهذِه الوَثيقَةُ
> تُجيبُ ثَلاثَةَ أَسئِلَةٍ عَمَلِيَّة: **ما الَّذي يَنزِل؟ وما الَّذي
> لا يَنزِلُ ولِماذا؟ وماذا يَقَعُ على المُستَلِمِ بَعدَ أَن
> يَنزِل؟**
>
> **والمَصدَرُ الوَحيدُ لِلحَقيقَةِ هُوَ الكود** — `TenantExportLedger`
> و`TenantExportRedaction`. وأَيُّ رَقمٍ هُنا يُعادُ قِياسُه بِـ:
>
> ```bash
> dotnet test PlatformV1.slnx --filter FullyQualifiedName~TenantExportTests \
>   -l "console;verbosity=detailed" | grep 'فُحِصَ'
> ```

## ١. المَدخَل

| الخُطوَة | المَوضِع |
|---|---|
| ١ | `/` ← «لَوحَتي» |
| ٢ | `/studio` ← بِطاقَةُ المَتجَر |
| ٣ | `/studio/apps/{slug}` ← صَفُّ **«اُخرُج بِبَياناتِك»** في قِسمِ التَشغيل |
| ٤ | `/studio/apps/{slug}/export` ← زِرُّ **«نَزِّل حَقيبَةَ بَياناتي»** |
| ٥ | `POST /studio/apps/{slug}/export.zip` ← المِلَفُّ يَنزِل |

**مَن يَملِكُ الحَقّ**: مالِكُ المَتجَرِ وَحدَه
(`Tenant.OwnerUserId == StudioAuth.UserId`). **لا** صَلاحِيَّةُ إدارَةِ
مَتجَرٍ تُمنَحُ لِمُوَظَّف.

**وكُلُّ تَصديرٍ يُقَيَّد** في سِجِلِّ تَدقيقِ المَتجَرِ نَفسِه بِفِعلِ
`tenant.export` — يَراهُ المالِكُ في صَفحَةِ التَخارُج («آخِرُ
تَصدير: مَتى · بِمَن»)، ويَراهُ مُشرِفُ المَنَصَّةِ في
`/admin/audit/{slug}`.

## ٢. بِنيَةُ الحَقيبَة

```
wasayel-{slug}-{yyyyMMdd-HHmm}.zip
├── README.md          ← فَهرَسٌ بَشَريّ + مَسؤولِيَّةُ المُستَلِم
├── data/*.json        ← وَثائِقُ المَتجَر، مِلَفٌّ لِكُلِّ صِنف
├── tables/*.csv       ← نَفسُها جَداوِلَ — UTF-8 بِـBOM، تُفتَحُ بِالنَقر
├── owner/*.json|csv   ← بَياناتُ صاحِبِ المَتجَرِ نَفسِه
├── files/…            ← الكائِناتُ بِمَفاتيحِها (tenants/{slug}/…)
├── files/MISSING.txt  ← مَفاتيحُ في الوَثائِقِ بِلا كائِنٍ في المَخزَن
├── index.xlsx         ← فَهرَسٌ يُفتَحُ بِالنَقر: صِنفٌ · عَدَدٌ · مِلَفّ
└── manifest.json      ← فَهرَسٌ آلِيّ + sha256 لِكُلِّ مَدخَل
```

**‏`manifest.json` آخِرُ مَدخَلٍ عَمداً** — يَحمِلُ بَصمَةَ كُلِّ ما
قَبلَه. **و`README.md` أَوَّلُه** — أَوَّلُ ما يَفتَحُه المُستَلِم.

**وأَسماءُ المَداخِلِ ASCII**: الاسمُ العَرَبيُّ في zip يُشَوَّهُ عِندَ
أَدَواتٍ لا تَقرَأُ رايَةَ UTF-8. المُحتَوى عَرَبيٌّ كامِلاً.

## ٤. ما لا يَخرُج — ولِماذا

### ٤-أ. أَصنافٌ كامِلَة (‏10)

| الصِنف | التَصنيف | السَبَب |
|---|---|---|
| `TenantPlan` | عامّ | باقَةُ المُستَأجِرِ **في وَسايِل** وسِعرُها. جَدوَلٌ بِلا `tenant_id` = قائِمَةُ عُملاءِ وَسايِلَ التِجارِيَّة. وحالَتُها يَراها المالِكُ في شاشَةِ الفَوتَرَة |
| `PlatformSettings` | عامّ | إعداداتُ المَنَصَّةِ نَفسِها |
| `PlatformPlanPayPal` | عامّ | رَبطُ باقاتِ المَنَصَّةِ بِخُطَطِ المُزَوِّد |
| `PayPalWebhookRecord` | عامّ | أَثَرُ مَنعِ تَكرارِ رِسائِلِ المُزَوِّد |
| `PayPalOrderRecord` · `PaddleTransactionRecord` | عامّ | مُعامَلاتُ **كُلِّ** المُستَأجِرينَ في حِسابِ المَنَصَّةِ التِجارِيّ |
| `ApiKeyDocument` | اعتِماد | تَجزئاتُ مَفاتيح API في جَدوَلٍ عامّ. لا تُعكَسُ فَلا تَنفَعُ المُستَلِم — **والمَفاتيحُ تُدارُ مِن شاشَتِها** |
| `ApiIdempotencyRecord` | داخِليّ | سِجِلُّ «مَرَّةً واحِدَة» — أَثَرُ آلِيَّة |
| `AnalysisRunClaim` | داخِليّ | مِفتاحُ حَجزِ تَشغيلَةِ تَحليل |
| `AgentSession` | داخِليّ | مُحادَثَةُ كونسولِ وَكيلِ المَنَصَّة. الفَرعُ الَّذي يُعطي جَلسَةً لِكُلِّ رائِدِ أَعمالٍ **بِصِفرِ مُنادٍ اليَوم** |

### ٤-ب. حُقولٌ تُحذَفُ مِن أَصنافٍ تَخرُج (‏5)

| الحَقل | السَبَب |
|---|---|
| `User.PushSubscriptions` | اعتِمادٌ حامِلٌ مَعقودٌ على زَوجِ VAPID واحِدٍ لِلمَنَصَّة: **لا يَنفَعُ المُستَلِمَ ويَضُرُّ مُستَخدِميه** |
| `AuditEntry.Ip` · `.UserAgent` | بَياناتٌ شَخصِيَّة، ومِنها عَناوينُ مُشرِفي المَنَصَّة |
| `ConsentRecord.Ip` · `.UserAgent` | نَفسُ الحُجَّة |

### ٤-ج. صُفوفٌ تُحجَبُ كامِلَةً

- قُيودُ التَدقيقِ الَّتي فاعِلُها `paypal ·` أَو `paddle ·` — أَثَرُ
  فَوتَرَةِ المَنَصَّةِ بِمُعَرِّفاتِ رِسائِلِ مُزَوِّدِها، مَكتوبٌ
  تَحتَ سلاجِ المُستَأجِر.
- صُفوفُ الاستيرادِ مِن `DeviceTokens` و`UserPushTokens` — **رُموزُ
  أَجهِزَةٍ حَيَّة** في أَعمِدَةٍ لَم يَقرَأها أَحَدٌ مِنّا، مَنقولَةٍ
  بِـ`SELECT *`.

### ٤-د. حُقولٌ تُعَتَّمُ بِالبِناء

`TenantProviderBinding.Values` يَمُرُّ بِـ`ProviderSecrecy.Censor`:
النَوعُ الَّذي يُعرَض (رابِطُ فاتورَةٍ مُيَسِّر) يَخرُجُ كامِلاً،
**وأَعمِدَةُ الظَرفِ (`Cipher`, `Nonce`, `Tag`, `KekVersion`, `Aad`) لا
تَخرُجُ أَبَداً** — وهي فارِغَةٌ اليَوم، والاستِثناءُ مَكتوبٌ قَبلَ أَن
تَمتَلِئ.

### ٤-هـ. وما لا يُصَدَّرُ لِسَبَبٍ بِنيَويّ

- **الكائِناتُ اليَتيمَة**: مِفتاحُ مِلَفٍّ لا رابِطَ لَه في أَيِّ
  وَثيقَة. `IFileStorage` بِلا عَمَلِيَّةِ سَرد، فَالمَفاتيحُ تُشتَقُّ
  مِن الوَثائِق.
- **مَجرى الأَحداثِ الخام**: التَجميعاتُ كُلُّها `Snapshot(Inline)`
  فَالوَثيقَةُ كامِلَة؛ والأَحداثُ تَحمِلُ أَسماءَ أَصنافِنا
  الداخِلِيَّةَ و`seq_id` **عَدّاداً عالَمِيّاً** يُفشي حَجمَ
  المَنَصَّة.
- **أَيُّ سلاجٍ لا وَثيقَةَ `Tenant` لَه** — ومِنه بَقايا الاختِبارِ
  الحَيَّةُ في القاعِدَة.

## ٥. ما يَلزَمُ المُستَلِمَ أَن يَعرِفَه

> هذا النَصُّ **مَكتوبٌ في `README.md` داخِلَ الحَقيبَةِ نَفسِها**، لا
> في وَثيقَةٍ بَعيدَةٍ يُحالُ إلَيها. وما يَلي شَرحُه لِفَريقِنا.

الحَقيبَةُ تَحمِلُ **بَياناتٍ شَخصِيَّةً لِأَشخاصٍ حَقيقيّين**:
أَسماءً، وهَواتِفَ، وبُرُداً، وأَرقامَ هُوِيَّة، ونُصوصَ مُحادَثاتٍ
خاصَّةً بَينَ طَرَفَين.

1. **انتِقالُ الصِفَة.** كانَت وَسايِلُ **جِهَةَ مُعالَجَة** لِهذِه
   البَيانات، والمُستَأجِرُ **جِهَةَ تَحَكُّم**. وبِالاستِلامِ يَصيرُ
   المُستَلِمُ جِهَةَ التَحَكُّمِ وَحدَه.
2. **حُقوقُ أَصحابِ البَياناتِ تَنتَقِلُ مَعَها** — الوُصولُ
   والتَصحيحُ والإتلاف. يُطالَبُ بِها المُستَلِمُ بَعدَ اليَومِ لا
   نَحن.
3. **النَقلُ والتَخزينُ عَلَيه**: قَناةٌ مُعَمّاة، ولا بَريدَ ولا
   رابِطَ مَفتوح، وإتلافُ النُسَخِ الزائِدَة.
4. **الإبلاغُ عَن التَسَرُّب** بِالنِسبَةِ لِنُسخَتِه صارَ واجِبَه.
5. **النَقلُ خارِجَ المَملَكَة**: إن كانَ المُستَلِمُ أَو تَخزينُه
   خارِجَها، تُراجَعُ أَحكامُ نَقلِ البَياناتِ الشَخصِيَّةِ **قَبلَ**
   النَقلِ لا بَعدَه.

**وهذا وَصفٌ تَشغيليٌّ لا رَأيٌ نِظاميّ.** وصَفُ العَلاقَةِ (مُعالَجَةٌ
مُقابِلَ تَحَكُّم) **يُعرَضُ على مُستَشارٍ نِظاميٍّ قَبلَ بِناءِ
التِزامٍ تَعاقُدِيٍّ عَلَيه**، ولا يُبنى عَلَيه شَيءٌ اليَوم.

**ودَينٌ مُعلَنٌ يَمنَعُ إصدارَ وَثيقَةِ تَسليمٍ رَسمِيَّةٍ اليَوم**:
حُقولُ الكِيانِ النِظاميِّ لِلمَنَصَّةِ ما زالَت نائِبَةً غَيرَ
مَملوءَة (اسمُ الكِيان، السِجِلُّ التِجاريّ، العُنوانُ الوَطَنيّ،
القانونُ الحاكِم، بَريدُ التَواصُل — في `ar.json` تَحتَ
`platform.contact.*`). **ووَثيقَةُ تَسليمٍ بِلا اسمِ كِيانٍ نِظاميٍّ
لَيسَت وَثيقَة.**

## ٦. حُدودٌ تَشغيليَّةٌ مُعلَنَة

| الحَدّ | القيمَة | ماذا يَقَعُ عِندَ بُلوغِه |
|---|---|---|
| مُهلَةُ تَبريدٍ بَينَ تَصديرَين | **لا يوجَد** | يُقَرِّرُه صاحِبُ المَشروع؛ والقَيدُ المَكتوبُ في التَدقيقِ هُوَ ما يُقاسُ عَلَيه |
| سَقفُ المِلَفّاتِ في حَقيبَة | ‏64 MB (`TenantExportService.FileBudgetBytes`) | تُقَصُّ المِلَفّاتُ **ويُكتَبُ ذلك في الفَهرَس** |
| حَجمُ الحَقيبَةِ الَّذي يَقلِبُ الشَكل | ‏100 MB | يُنقَلُ التَوليدُ إلى مَخزَنِ الكائِناتِ ورابِطٍ مُنتَهي الصَلاحِيَّة (‏ADR-020 §٧) |
| بَوّابَةُ باقَة | **لا يوجَد، ولا يُضاف** | التَخارُجُ ميزَةٌ مَدفوعَة = حَبسٌ بِثَمَن، نَقيضُ الأَطروحَة |

**وقِراءَةٌ تَتَعَذَّرُ لا تُبتَلَع**: نَوعٌ حَيٌّ بِلا جَدوَلٍ في
الإنتاجِ يُعطي جَدوَلاً فارِغاً — **ويُكتَبُ سَبَبُ التَعَذُّرِ في
`manifest.json` و`README.md` وفي الشاشَة**، لِأَنّ جَدوَلاً فارِغاً
لِعَطَبٍ يُقرَأُ «لا بَياناتِ لَك».

يَخرُجانِ جَدوَلَينِ فارِغَينِ **ومَعَهُما سَبَبُ التَعَذُّرِ
مَكتوباً** في الفَهرَسَين وفي الشاشَة. وهذا هُوَ السُلوكُ المَقصود:
جَدوَلٌ فارِغٌ بِلا سَبَبٍ يَكذِب، وجَدوَلٌ فارِغٌ بِسَبَبِه يُقرَأ.
والجَدوَلانِ يُنشَآنِ بِأَوَّلِ كِتابَةٍ حَقيقيَّةٍ لِأَيٍّ مِنهُما،
فَلا هِجرَةَ تُنفَّذُ لِأَجلِ التَخارُج.

## ٨. مَسارُ النَقرِ كَما قيسَ — وما لَم يُقَس

**مِن إقلاعٍ بارِد** (‏2026-08-30، خادِمُ تَطويرٍ على فَرعِ Neon،
بِـ`curl` بِلا مُتَصَفِّح):

| الخُطوَة | المَقيس |
|---|---|
| `GET /` | ‏200 |
| `GET /studio/auth` | ‏200 |
| `POST /studio/auth/login` | ‏302 → صَفحَةُ التَحَقُّق |
| `POST /studio/auth/verify` | ‏302 → `/studio` **وكوكي الجَلسَةِ مَكتوب** |
| `GET /studio` · `/studio/apps/{slug}` · `/studio/apps/{slug}/export` | ‏200 · ‏200 · ‏200 |
| `POST /studio/apps/{slug}/export.zip` **بِجَلسَةٍ لَيسَت لِلمالِك** | ‏302 → `…/export?err=not_owner` |

**وبَوّابَةُ الإقلاعِ الإنتاجيِّ تَحمِلُ المَسارَينِ دائِماً**:
`GET …/export` ← ‏200، و`POST …/export.zip` بِلا جَلسَة ← ‏**302**.
و‏200 على الثاني **عَطَبٌ أَمنيٌّ لا نَجاح**.

**وما لَم يُقَس — يُقالُ ولا يُبتَلَع**: التَنزيلُ الفِعليُّ
بِمُتَصَفِّحِ **مالِكٍ** لَم يُجَرَّب، لِأَنّ إنشاءَ جَلسَةِ استوديو
جَديدَةٍ يُعطي مُستَخدِماً **لا يَملِكُ مَتجَراً** (‏`StudioOwnershipSeeder`
يُسنِدُ اليَتيمَ إلى **أَقدَمِ** مُستَخدِمٍ لا إلى الداخِلِ الجَديد)،
والدُخولُ بِحِسابِ مالِكٍ قائِمٍ لَيسَ لِوَكيلٍ أَن يَفعَلَه. **والحَلقَةُ
غَيرُ المَقيسَةِ سَطرٌ واحِد**: `Results.File(result.Zip!, …)`. أَمّا
الحُمولَةُ نَفسُها فَمُنتَجَةٌ ومَقيسَةٌ لِلمَتاجِرِ الخَمسَةِ كُلِّها
في §٧ أَعلاه.
