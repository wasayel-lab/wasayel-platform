# تَوصيف المَظهَر — لَقطَة الأَساس

هذا المُجَلَّد لَيسَ تَوثيقاً، بَل **أَداة قِياس**. مُحتَواه لَقطَة
مُلتَقَطَة مِن خادِم حَيّ **قَبل** أَن يُحَوَّل سَطر CSS واحِد إلى رَمز
تَصميم، وغايَتُها جَواب سُؤال واحِد بِـ`cmp` لا بِالعَين:

> هَل تَغَيَّرَ بايت واحِد في ما يَراه اللاعِب، خارِج كُتلَة الرُموز
> الجَديدَة؟

## ما فيه

| المِلَفّ | الصَفحَة |
|---|---|
| `baseline/ashare-portal.html` | `/ashare` — بَوّابَة عَرض المُستَثمِرين |
| `baseline/ashare-role-customer.html` | `/ashare/r/customer` |
| `baseline/ashare-role-host.html` | `/ashare/r/host` |
| `baseline/ashare-role-vendor.html` | `/ashare/r/vendor` |
| `baseline/ashare-explore.html` | `/ashare/explore` |
| `baseline/adwar-demo-portal.html` | `/adwar-demo` — ساحَة التَّجرِبَة |
| `baseline/css/*.css` | أَوراق الأَنماط الثَّمانِيَة كَما تُقَدَّم |

`ashare` هُنا هو **مِقياس التَّكافُؤ الصِفريّ الحَيّ**: عَرض
المُستَثمِرين الَّذي لا يَتَغَيَّر فيه بِكسل ولا بايت. وُجودُه في
اللَقطَة لَيسَ لِلتَوثيق بَل لِيُفشِل البَوّابَة إن تَغَيَّر.

## التَّطبيع — واحِد فَقَط

يُستَبدَل مُحتَوى تَعليق `Blazor-Server-Component-State` بِـ`NORMALIZED`.
وهذا **مُقاس لا مُقَدَّر**: طَلَبان مُتَتالِيان لِنَفس الصَفحَة
يَختَلِفان في هذا السَطر وَحدَه (‏6 أَسطُر `diff`، كُلُّها هُوَ). لا
تَطبيع آخَر، ولا «تَجاهُل المَسافات»، ولا مُقارَنَة «تَقريبِيَّة».

## الاستِعمال

```bash
# ١. الالتِقاط (مَرَّة واحِدَة، قَبل التَّحويل)
scripts/capture-appearance.sh

# ٢. البَوّابَة (بَعد كُلّ تَحويل)
scripts/compare-appearance.sh
```

## الأَداة نَفسُها مَقيسَة لا مَظنونَة

أَداة تُجيب «مُطابِق» دائِماً عَديمَة القيمَة. لِذلك عُويِرَت
بِطَفرَة مَقصودَة قَبل الاعتِماد: تَبديل `<base href="/">` بِـ
`<base href="/x">` في لَقطَة الأَساس — **حَرف واحِد** — فَأَعطَت
`✗ ashare-portal.html`، وعادَت خَضراء فَور إرجاع اللَقطَة. الحُكم
لِلأَداة، بِشَرط أَن تَكون الأَداة نَفسُها قَد كَذَبَت مَرَّةً تَحت
الطَلَب.
