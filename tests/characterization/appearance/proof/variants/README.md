# البُرهان الحَيّ لِلمُتَغايِرات والحُزَم

هذا المُجَلَّد مَخرَج `scripts/prove-theme-variants.sh`. المِلَفّات
تُكتَب عِندَ التَشغيل ولا تُؤَلَّف بِاليَد.

## ما يُثبِتُه التَشغيل

```bash
scripts/prove-theme-variants.sh <admin-phone>
```

| الخُطوَة | الدَعوى المَفحوصَة |
|---|---|
| ٠ | ‏PID الخادِم قَبل كُلّ شَيء |
| ١ | الصَفحَة بِلا جَلسَة: لا نَموذَج تَطبيق واحِد · نُقطَة التَطبيق بِلا جَلسَة: ‏403 |
| ٢ | الصَفحَة بِجَلسَة مُخَوَّلَة: ثَلاث بِطاقات بِأَسمائِها |
| ٣ | **سالِب**: حُزمَة مَجهولَة ← إعادَة تَوجيه بِـ`err` ولا بايت يَتَغَيَّر |
| ٤ | «لَيل رَملِيّ» ← ‏`:root` تَغَيَّرَ، والأَصناف الثَلاثَة تَغَيَّرَت، و`ashare` بايتاً بِبايت |
| ٥ | «الأَزرَق الافتِراضيّ» ← **العَودَة إلى الصِفر**: كُتلَة `adwar-demo` = كُتلَة `ashare` حَرفاً، وبَوّابَتُه = لَقطَة الأَساس بايتاً بِبايت |
| ٦ | «أَخضَر الواحَة» ← الحالَة الباقِيَة، ومَتجَرانِ بِهُوِيَّتَين مِن نَفس المَصدَر |
| ٧–٨ | ‏PID بَعدَ كُلّ ذلكَ = ‏PID قَبلَه |

الخُطوَة ٥ هي الأَقسى وهي الأَهَمّ: لَولاها لَكانَ «الافتِراضيّ هو
الشَكل الحاليّ حَرفاً» دَعوى مَكتوبَة في مُصادِق، لا مُقارَنَةً
بايتِيَّة عَلى صَفحَة حَيَّة.

## حالَة ‏2026-08-10 — التَشغيل لَم يَجرِ

**السَبَب خارِج المُستودَع**: نُقطَة Postgres (‏Neon) رَفَضَت الاتِّصال
في مُنتَصَف الجَلسَة بِـ

```
Npgsql.PostgresException 28000: The requested endpoint could not be found…
Npgsql.PostgresException 28P01: password authentication failed for user 'neondb_owner'
```

ولَيسَ مِن أَثَر التَغيير: نَفس سِلسِلَة الاتِّصال، مَقروءَةً مِن نَفس
المِلَفّ، تَفشَل مِن **حَقيبَة اختِبار عارِيَة** لا عَلاقَة لَها
بِالخادِم (`LiveThemeProofTests`). وكانَت تَعمَل قَبلَها بِدَقائِق في
نَفس الجَلسَة.

**وما جَرى فِعلاً قَبل الانقِطاع، وهو أَثقَل ما في المَوجَة**: بَوّابَة
القَبول `scripts/compare-appearance.sh` رَكَضَت عَلى خادِم حَيّ يَحمِل
طَبَقَة المُتَغايِرات كامِلَةً، فَأَعطَت **✓ لِلصَفَحات السِتّ كُلِّها**
— لا بايت تَغَيَّرَ خارِج كُتلَة الرُموز. وهي بِعَينِها دَعوى التَكافُؤ
الصِفريّ، مَقيسَةً لا مُدَّعاةً.

يَبقى غَير مَقيس حَيّاً: التَبديل الثُلاثيّ نَفسُه. الأَمر واحِد
وجاهِز، والحَقيبَة تُغَطّي كُلّ ما لا يَحتاج شَبَكَة (‏464 اختِباراً).
